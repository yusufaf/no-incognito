One more step

Firefox only lets extensions see private windows if you allow it. Without that, No Incognito cannot close them.

  1. Open about:addons and choose No Incognito.
  2. Set Run in Private Windows to Allow.

Private browsing is always on

Firefox is set to always use private browsing (browser.privatebrowsing.autostart), so every window is private and there is no normal window to move your tabs to. No Incognito stopped instead of closing windows in a loop.

Turn off "Always use private browsing mode" in Settings → Privacy & Security → History, then restart.
