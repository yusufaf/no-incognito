# No Incognito

Hides every "open in private window" entry in Zen Browser: the File and app menus, the link context menu, bookmark, history and sidebar menus, and synced tabs.

Each group has a checkbox in the mod's settings (all off, meaning hidden). Tick one to show that group again.

This mod only hides menu items. It cannot block `Ctrl+Shift+P` or the taskbar jump list. Pair it with the [No Incognito extension](https://github.com/yusufaf/no-incognito), which closes any private window that does open and moves its links to a normal window.

Tested with Zen 1.23.1b.
